## Implementation Notes

- The Field Core and Structural Prediction Model are part of the data / structure side.
- Jarvis and Crab Router are part of the text / planning / execution side.
- Crab Router is designed as a possible Jarvis extension.
- Parameter-Golf-inspired GPT training is a separate evidence case study, not a core system.

## Public Presentation Rule

Each project should be described according to its maturity level.

Use conservative wording for conceptual and prototype systems. Use measurable wording only where code, logs, or metrics are included.
